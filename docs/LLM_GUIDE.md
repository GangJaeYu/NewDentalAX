# LLM_GUIDE — AI(LLM API) 쉽게 이해하기

> 이 문서는 코딩을 모르는 분을 위해 썼습니다. 실제 키 입력 순서는 [설치·사용 안내서(GUIDE)의 "AI 키 넣기"](GUIDE.md#ai-키-넣기), 비용 계산은 [COST.md](COST.md)를 함께 보세요.
> 확인일: 2026-11-03. 공급자 사이트의 메뉴 이름은 자주 바뀝니다. 아래 이름과 조금 달라도 같은 뜻의 메뉴를 찾으면 됩니다.

## LLM API란

**LLM**(대규모 언어 모델)은 글을 읽고 쓰는 AI입니다. ChatGPT, Claude, Gemini가 모두 LLM입니다.
**API**는 프로그램끼리 대화하는 창구입니다.

쉽게 비유하면 이렇습니다.

| 비유 | 실제 |
|---|---|
| 외부 **번역·문서 대행 업체** | AI 공급자(Anthropic, OpenAI, Google) |
| 업체에 일을 맡기는 **전용 주문 창구** | API |
| 우리 병원 **거래처 카드(회원 번호)** | API 키 |
| 맡긴 **글자 수만큼 내는 요금** | 토큰 요금 |
| 주문서를 대신 써서 보내 주는 **실장님** | 이 프로그램의 서버 |

- 직원이 화면에서 "AI 문서 작성"을 누르면, 서버(실장님)가 **환자 정보가 섞였는지 먼저 확인**하고 주문서(프롬프트)를 만들어 업체(공급자)에 보냅니다.
- 업체가 초안을 돌려주면 화면에 보여 주고, **쓴 양과 요금**을 장부(AI 사용량·비용)에 적습니다.
- 거래처 카드(키)는 서버 금고에 **암호화해** 보관하고, 직원 화면에는 보여 주지 않습니다.
- 카드가 없으면(키 없음) 실장님이 **예시 답(데모 응답)** 을 대신 보여 줍니다. 요금은 0원입니다.

ChatGPT·Claude **월 구독**(웹사이트에서 쓰는 것)과 **API**는 다른 상품입니다. 구독이 있어도 API 요금은 따로 냅니다. 대신 API는 쓴 만큼만 내고, 이 병원 규모에서는 보통 한 달 몇천 원입니다.

## 공급자별 API 키 발급

공급자는 **셋 중 하나만** 골라도 됩니다. 어느 곳이 좋은지는 [COST.md의 추천 조합](COST.md#추천-조합)을 보세요.

모든 공급자에 공통으로:

1. 병원 대표 이메일로 **회원 가입**을 합니다.
2. **결제 수단(카드)** 을 등록하고 **선불 크레딧**(예: 5~10달러)을 넣거나 사용량 결제를 켭니다. 결제가 없으면 키가 있어도 AI가 동작하지 않습니다.
3. **API 키를 만들고** 복사합니다. 키는 **만들 때 딱 한 번만** 보여 줍니다. 바로 이 프로그램에 붙여 넣으세요.
4. 공급자 사이트에서 **월 사용 한도(알림)** 를 걸어 두면 이중으로 안전합니다.

### Anthropic (Claude)

1. https://platform.claude.com 에 들어가 가입·로그인합니다(Claude Console).
2. 왼쪽 메뉴 **Settings(설정) → Billing(결제)** 에서 카드를 등록하고 크레딧을 넣습니다.
3. **Settings → API keys** 에서 **Create key(키 만들기)** 를 누릅니다.
4. 키 이름을 적습니다(예: `clinic-ax`). 만들어진 키(`sk-ant-`로 시작)를 **복사**합니다.
5. 버튼이 눌리지 않으면 계정 권한이 부족한 것입니다. 조직 관리자에게 권한을 받거나 키를 만들어 달라고 합니다.

공식 안내: https://platform.claude.com/docs/en/get-api-key

### OpenAI

1. https://platform.openai.com 에 들어가 가입·로그인합니다. (chatgpt.com 과는 다른 곳입니다)
2. 오른쪽 위 **설정(톱니) → Billing(결제)** 에서 카드를 등록하고 크레딧을 넣습니다.
3. https://platform.openai.com/api-keys 에서 **Create new secret key(새 비밀 키 만들기)** 를 누릅니다.
4. 이름을 적고 만들면 키(`sk-`로 시작)가 한 번 보입니다. **복사**합니다.

공식 안내: https://developers.openai.com/api/docs/pricing (요금), https://developers.openai.com/api/docs/guides/your-data (데이터 정책)

### Google (Gemini)

1. https://aistudio.google.com 에 Google 계정으로 로그인합니다.
2. 왼쪽 **Get API key(API 키 받기)** → **Create API key(API 키 만들기)** 를 누릅니다. (Google Cloud 프로젝트가 함께 만들어집니다)
3. **반드시 결제(유료 등급)를 연결하세요.** API 키 화면의 **Set up billing(결제 설정)** 에서 카드를 등록합니다.
   - **무료 등급은 보낸 내용을 Google이 제품 개선에 쓰고, 사람이 읽어 볼 수도 있습니다.** 병원 업무 글에는 쓰지 마세요.
   - 유료 등급은 제품 개선에 쓰지 않습니다(자세한 내용은 [COST.md 데이터 정책](COST.md#공급자별-데이터-정책)).
4. 만들어진 키(`AIza`로 시작)를 **복사**합니다.

공식 안내: https://aistudio.google.com/docs/pricing (요금), https://aistudio.google.com/docs/terms (약관)

## 토큰과 요금

**토큰**은 AI가 글을 세는 단위입니다. 대략 **한글 1~2글자 = 1토큰**, 영어 단어 1개 = 1~2토큰 정도입니다.

요금은 **보낸 글(입력)** 과 **받은 글(출력)** 을 따로 셉니다.

```
1회 요금(달러) = (입력 토큰 × 입력 단가 + 출력 토큰 × 출력 단가) ÷ 1,000,000
1회 요금(원)   = 1회 요금(달러) × 환율(기본 1,450원, 관리 화면에서 바꿈)
```

- 단가는 **100만 토큰당 달러**로 표시합니다. 예: 입력 $1 / 출력 $5.
- **출력이 입력보다 3~6배 비쌉니다.** 그래서 긴 문서를 쓰게 할수록 비용이 늘어납니다.
- **등급**: 이 프로그램은 기능마다 모델 등급을 정해 둡니다.
  - **빠름**(가장 싼 모델): 빠른 요청, 스크립트, 템플릿, 리뷰 답글, 회의록, 광고 점검, 월간 요약
  - **표준**: 문서 작성, 원내 도우미, 홍보 글, 채용, 온보딩, 명세서 사진 읽기
  - **고급**: 문서 작성에서 직접 "고급"을 고를 때만
- 예시(OpenAI 표준 모델 $1 / $5 기준): 안내문 한 장(입력 600토큰 + 출력 2,000토큰) ≈ 0.0106달러 ≈ **약 15원**.
- 실제 쓴 토큰과 금액은 **관리 → AI 사용량·비용** 에 호출마다 기록됩니다(글 내용은 저장하지 않음).
- 병원 규모별 월 예상 비용은 [COST.md](COST.md#병원-규모별-월-비용)에 있습니다.

## 키 관리 안전 수칙

API 키는 **병원 법인 카드 번호**와 같습니다. 누가 알면 우리 돈으로 AI를 쓸 수 있습니다.

1. **키는 이 프로그램 관리 화면에만** 붙여 넣습니다. 카카오톡·문자·메일·메모장에 적어 두지 않습니다.
2. 키를 넣은 뒤 화면에는 **끝 4자리만** 보입니다. 원래 키는 다시 볼 수 없으니, 잃어버리면 공급자 사이트에서 **새로 만들고 옛 키는 지웁니다.**
3. **직원에게 키를 알려 주지 않습니다.** 직원은 키 없이 프로그램을 통해 AI를 씁니다.
4. 공급자 사이트에서 **월 사용 한도**를 걸고, 이 프로그램의 **월 예산**(80% 경고, 100% 차단)도 함께 씁니다.
5. **백업 폴더에는 키를 푸는 열쇠(`secret.key`)가 들어 있습니다.** 백업을 밖으로 가져갈 때는 잠긴 곳에 보관합니다. 백업을 잃어버리면 바로 키를 바꿉니다.
6. 퇴사자가 공급자 계정에 접근할 수 있었다면 **키를 새로 만들고** 옛 키를 지웁니다.
7. 6개월~1년에 한 번은 키를 새로 만들어 바꾸면 더 안전합니다.
8. **환자 개인정보는 AI 입력에 넣지 않습니다.** 프로그램이 주민번호·카드번호는 막고 전화번호·이메일은 가리지만, 이름은 알아보지 못합니다.

## 이 프로그램에 키 넣기

1. 원장·관리자 계정으로 로그인합니다.
2. 왼쪽 메뉴 **관리 → AI 설정·예산** 을 엽니다.
3. 오른쪽 **API 키** 에서 공급자 칸에 키를 붙여 넣고 **"키 저장"** 을 누릅니다. "키 저장됨"으로 바뀌면 됩니다.
4. 왼쪽 **AI 공급자** 에서 그 공급자를 고릅니다.
5. **월 예산(원)** 과 **경고 비율(%)** 을 정하고 **"설정 저장"** 을 누릅니다.
6. 아래 **AI 시험해 보기** 에서 짧은 요청을 보내 답이 오는지 확인합니다.
7. 모델 이름과 단가는 같은 화면 아래 **모델 표**에 있습니다. 공급자가 가격을 바꾸면 여기서 고칩니다(확인 날짜·출처 칸도 함께).

키를 지우거나 공급자를 "데모(키 없음)"로 바꾸면 언제든 데모 모드(비용 0원)로 돌아갑니다.
